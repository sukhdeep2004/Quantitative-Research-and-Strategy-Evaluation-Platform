# Quantitative Research and Strategy Evaluation Platform

A FastAPI service that backtests trading strategies on historical prices from Yahoo Finance, saves every run to Azure SQL, and exposes the results through a REST API, HTML tables with CSV export, and a Power BI report.

## Features

**Strategies**

- Moving average crossover (20 / 50 day)
- RSI (14 day, 30 / 70 thresholds)
- MACD (12 / 26 / 9)
- Bollinger Bands (20 day, 2 standard deviations)
- Cointegration pairs trading on two tickers: rolling 60-day hedge ratio, 30-day z-score of the spread, enter beyond ±2 and exit inside ±0.5. The Engle-Granger p-value is reported for each pair.

All parameters live in `quant/backtest.py` (`STRATEGIES` and `COINTEGRATION_PARAMS`).

**Metrics saved for every run**

- Sharpe ratio (annualized, zero risk-free rate)
- Maximum drawdown, total return and win rate, all as percentages
- Final equity (starting from 1.0)
- `num_trades`, which counts the days with a position, and win rate, which is the share of those days with a positive return

Each row also stores the strategy parameters (`parameters`, JSON) and the git version of the code that produced it (`code_version`, with `-dirty` if there were uncommitted changes), so results stay comparable as the code changes.

**Viewing results**

- `/backtest-results`: table filterable by ticker, strategy, minimum Sharpe and profit / loss, with CSV export
- `/docs`: Swagger UI generated by FastAPI
- `Quant Research Dashboard.pbix`: Power BI report built on the `backtest_results` table, downloadable from `/download-powerbi`

## Setup

### Prerequisites

- Python 3.9 or newer
- [Microsoft ODBC Driver 18 for SQL Server](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server), which `pyodbc` uses to reach Azure SQL
- An Azure SQL database whose firewall allows your IP address

### Install

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Configure the database

Copy the template and fill in your connection string. `.env` is git-ignored, so never put credentials in `db/config.py`.

```bash
cp .env.example .env
```

```
DATABASE_URL="mssql+pyodbc://<username>:<password>@<server>.database.windows.net:1433/<database>?driver=ODBC+Driver+18+for+SQL+Server"
```

### Create the tables

Run from the repository root:

```bash
python -m db.init_db
```

This creates missing tables and adds any columns introduced since your table was created, so run it again after pulling changes that add columns.

### Load sample data (optional)

Backtests AAPL, MSFT, GOOGL, AMZN, TSLA, META and NVDA with every strategy, plus the KO/PEP and V/MA pairs, over the last year:

```bash
python test_db.py           # adds to existing results
python test_db.py --reset   # deletes all existing results first
```

### Run

```bash
uvicorn main:app --reload
```

Open http://localhost:8000.

## API

| Method | Path | Description |
| --- | --- | --- |
| GET | `/` | Home page with summary stats |
| GET | `/run-all-backtests` | Form to run every strategy on a ticker, optionally with a pair ticker |
| POST | `/run-all-backtests-api` | JSON body `ticker`, `start_date`, `end_date`, optional `pair_ticker` |
| POST | `/run-backtest` | Moving average backtest for one ticker |
| POST | `/run-pair-backtest` | Cointegration backtest for `ticker` against `pair_ticker` |
| GET | `/backtest-results` | HTML results table (`?limit=` defaults to 100) |
| GET | `/dashboard-data` | Aggregated KPIs and recent results as JSON |
| GET | `/download-powerbi` | Downloads the `.pbix` report |

Example:

```bash
curl -X POST http://localhost:8000/run-pair-backtest \
  -H "Content-Type: application/json" \
  -d '{"ticker": "KO", "pair_ticker": "PEP", "start": "2024-01-01", "end": "2025-01-01"}'
```
